# Card Exchange

Trade in cards you're no longer using for points, redeemable for a small selection of items.

!!! info "Quick Facts"
    - **NPC:** Putty
    - **Location:** Prontera, near Main Office (`/navi prontera 130/192`)
    - **Rate:** 10 points per card

![Putty](img/Putty.png)
