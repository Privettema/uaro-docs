# 📢 Guild Starter Support System

> **Support system for newly created guilds**
> Designed for smooth PvE progression without skipping game content.

---

## 📝 Eligibility Requirements

| Requirement        | Description                                             |
| ------------------ | ------------------------------------------------------- |
| 👥 Minimum Members | Guild must have **10 unique members**                   |
| 🔁 One-Time Claim  | Each guild may receive the package **only once**        |
| 🧾 GM Verification | Distribution is handled **manually after verification** |

---

## 🎁 Starter Package Contents

!!! info

    Designed to support PvE progression without skipping content.

## 📦 Claiming Process

1. Verified guilds will be **recalled by a GM** into a restricted area.
2. Items are obtained through a **designated NPC**, similar to the beginner reward NPC in Prontera.
3. Once the reward box is opened, the **14-day timer** activates for all items.
4. Boxes must be claimed and used within **30 days**.

   * Unclaimed boxes will be automatically **deleted**.

---

## 🚫 Abuse Prevention

!!! danger
     Any attempt to exploit this system (fake guilds, multi-accounting, etc.) will result in:  
     
     * ❌ **Permanent account bans**
     * ❌ **Hardware bans for all linked accounts**

This system is intended **only for new incoming guilds**.
Existing players and accounts will *not* receive these rewards.
