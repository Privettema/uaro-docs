# Patch Notes - November 3, 2026

!!! warning "Important"
    Make sure your client is patched using the patcher -
    this is important to avoid in-game errors and crashes.

---

## 🎮 Gameplay

### Super Novice Fury

Added an option to activate **Fury** with a single line, using the pre-existing requirements for Super Novice (to help prevent muting yourself):

```text
Dear angel, can you hear my voice? I am <name> Super Novice~ Help me out~ Please~ T_T
```

- If **Fury** is already active, re-triggering it will fail.

### Offline Guild Invites

Offline guild invites (`/guildinvite`) have been improved:

- The inviter is now told if the invite is accepted or declined.
- Characters already in a guild are refused right away.

### Other Changes

| Change | Description |
|--------|-------------|
| **Chatrooms** | Chatrooms are now blocked around the event NPCs in western Prontera |

## ⌨️ Commands

### @friendinvite

Added `@friendinvite <character name>`:

- Works normally if the member is online.
- Offline characters receive the request when they log in.
- You can't invite your own characters.
- `2` hour expiration from the time of the request if not answered (a server restart also clears pending requests).

### @homtalk & @pettalk

`@homtalk <message>` and `@pettalk <message>` are now available to players:

- Type messages through your companions as a medium.
- All chat through companions will be logged and treated the same as coming from you.

| Change | Description |
|--------|-------------|
| **`@restock` / `@qstore`** | Capacity for both lists and item count within lists raised from `20` to `40` |
| **`@lootconfig`** | Total list count increased from `20` to `40`. Total item count within lists increased from `20` to `100` max |

| Item | Changes |
|------|---------|
| **Antelope Horn** | Cart restrictions lifted. **Discount** / **Overcharge** now apply to it as well |

### Pet Accessory Box

Added the **Pet Accessory Box** (`16358`):

- Random box that grants a random pet armor for any obtainable pet that has an armor (`39` total).
- Same chance for any item in the pool, including already obtainable pet armors.
- **Hobota** mission shop at `30` points.
- Drops from the **Slot Machine** at the same rate as the **Taming Gift Set**.

:point_right: **[Pet Accessory Box](../../item-changes.md#pet-accessory-box)**

## 🐾 Pets

### Pet Skins

- When you return your pet to its egg and rehatch it, your previous pet skin now stays active, just as it does when swapping eggs with a **Pet Incubator**, including after logging out or switching characters. Saved per character.
- Equipped pet armor accessories now display matching your skinned pet (equip/unequip the accessory on your active pet as normal; it stays on the egg until you unequip it).
- Pet armor accessories can now be equipped on pets that have no native accessory but are skinned into one that does.
