# Patch Notes - July 7, 2026

!!! warning "Important"
    Make sure your client is patched using the patcher -
    this is important to avoid in-game errors and crashes.

---

## 🎮 Gameplay

| Change | Description |
|--------|-------------|
| **Sun Kissed Goal Lowered** | The number of **Sunrings** the server must defeat together to trigger a **Sun Kissed** buff ([Beat the Heat](../../Summer_Event_2026.md#beat-the-heat) event) has been reduced from `15,000` to `12,000`, so the hourly random buff activates more often |

| Change | Description |

| **Payon Warp Point Moved** | The Kafra warp destination for Payon now drops you at a new arrival spot `(158, 157)` instead of the old one |
| **Tool Dealer in Prontera Market** | A **Tool Dealer** is now available in the Prontera Market (`prt_mk`, `156, 149`) |

## 🎒 Items

| Change | Description |
|--------|-------------|
| **New Weapon: Muramasa [2]** | A slotted **Muramasa** is now available. **Leablem**, the S-Class socket enchanter, can now attempt to add slots to a Muramasa, turning a slotless Muramasa into the 2-slot version. Cost: `2,000,000` zeny plus `5` **Oridecon** and `10` **Steel**, with a `10%` success rate. Failure destroys the weapon and the materials |
| **Noble Cross Refine Scaling** | The **Noble Cross** now scales its auto-cast **Turn Undead** chance with refine level. At refine `4` and below it keeps the usual `5%` proc. From refine `5` upward the chance rises about `1%` per refine level (refine `5` is `6%`, refine `10` is `11%`). All other stats (`125` MATK, Holy element, and Undead SP drain and gain) are unchanged |
| **Holy Arrow Quiver at Jaax** | **Inventor Jaax** in Payon now offers a **Holy Arrow Quiver**. Bring him Holy Arrows and he will pack `500` into a quiver for `500` zeny, like his other quiver services |
| **Dead Branch Disabled on More Maps** | **Dead Branch** and **Bloody Branch** can no longer be used on Comodo Field 7 (`cmd_fild07`), Ayothaya Field 1 (`ayo_fild01`), Odin Temple 2F (`odin_tem02`), and Thor Volcano 2F (`thor_v02`) |

!!! note "GvG Restriction"
    **Muramasa [2]** is restricted in GvG.

## 🏰 Dungeons

| Change | Description |
|--------|-------------|
| **Bio Labs Safe Zones** | Added protected safe zone tiles at the warp entrances of **Bio Laboratory 3 and 4**. You now arrive on a safe tile where you cannot be attacked and cannot attack. Step off the tile to engage. You cannot walk back onto the pad, so it cannot be abused for camping. This adds anti-spawn-kill protection for these high-traffic MVP floors |
| **Ice Wall Re-enabled in Bio Labs** | Removed the restriction that blocked the **Ice Wall** skill in parts of **Bio Laboratory 3 and 4**. Wizards can place Ice Wall in those areas again |

---

## 🐾 Monsters

| Change | Description |
|--------|-------------|
| **MVP Tomb Revamp** | MVP death timers and tombs now survive server restarts. Killing an MVP right before a restart no longer resets its respawn timer. Tombs, which show who last defeated the boss and the top `3` damage dealers, now also appear for special script-summoned bosses: **Bio Labs 3 and 4**, **Wounded Satan Morroc**, **Lord of Death** in Niflheim, and **Thanatos Phantom** |
| **Bio Lab 3 Random Boss Spawns** | The six mini bosses in **Bio Laboratory 3** (**Lord Knight Seyren**, **Whitesmith Howard**, **Assassin Cross Eremes**, **Sniper Cecil**, **High Priest Margaretha**, and **High Wizard Kathryne**) now spawn at random locations across the whole map instead of fixed spots. No more camping known corners |

!!! note "MVP Tomb Revamp"
    Will not take effect until the next server downtime.

## 🛠️ Fixes

| Change | Description |
|--------|-------------|
| **Sun Kissed ASPD Buff Boosted** | The attack-speed version of the **Sun Kissed** community buff ([Beat the Heat](../../Summer_Event_2026.md#beat-the-heat) event) was increased from `0.5%` to `5%` ASPD |
| **Battlegrounds Happy Hour Extension Fixed** | During the Summer 2026 event, **Battlegrounds Happy Hour** runs `30` minutes longer than usual. That extra half hour now correctly keeps the bonus badge rewards active for its full duration. Previously the bonus ended on the normal schedule, so the `30` minute extension granted no extra reward despite the delayed end announcement |
