## ⚔️ Battlegrounds

| Fix | Description |
|-----|-------------|
| **KvM Score Engine** | The **KvM** score engine now loads properly after the teams are stacked and before the match starts |

## ⚔️ PvP

### Private Arenas

**Private Arenas** have been added to the **PvP Warper** in Prontera (`156, 195`):

- Choose **Private Arena**, then **Create Private Arena** and pick one of five maps - Prontera,
  Izlude, Payon, Alberta or Morroc.
- You are given a `6` character code. Anyone who picks **Join Private Arena** and enters that
  code is warped straight in.
- Eight rooms per map, `38` private arenas can run at the same time. If every room on that map
  is taken you are asked to try another map.
- A room stays yours for `1` hour. After that it can be handed to the next player who asks for
  one, and anyone still inside is warped to their save point with a warning first.
- Same `100` player cap and the same item restrictions as the public arenas.

## 🎮 Commands

### @vendrecap

**`@vendrecap`** has been reformatted to include more information:

- Now shows your shop name, when the shop opened and closed, and your total zeny earned across
  the whole run.
- A new **View All** option lists every item together with each individual sale - buyer name,
  timestamp and amount.

| Change | Description |

## ⚔️ Skills

### Party Buff Animations

The animation delay from buffs cast by party members has been removed. The animation still plays
for the caster:

- Covers **Angelus**, **Magnificat**, **Gloria**, **Wind Walk**, **Adrenaline Rush**,
  **Full Adrenaline Rush**, **Weapon Perfection**, **Over Thrust**, **Help Angel** and the
  Cash Shop **Blessing**, **Increase AGI** and **Assumptio**.
- Party members now receive the buff instantly, with just the effect and a floating skill name
  over their head.

| Change | Description |
|--------|-------------|
| **Impositio Manus** | Now grants MATK on top of its ATK bonus: `1%` per skill level, up to `5%` at level `5`. No effect on WoE and GvG castle maps |
| **Mind Breaker** | Now reduces the target's hard MDEF (the percentage reduction from equipment) everywhere except WoE and GvG castles, where it keeps reducing soft MDEF (the flat reduction from INT) as before. The status icon has been updated either way |

### Bastion Enchants

Two new **Bastion enchants** are available from **Vulcarion** in Veins (`223, 133`), at `10`
**Bastion Coins** each, same as the existing five:

- **SP Consumption** `-20%`

Both can be removed again by the **Master Craftsman** in Prontera, and like the other five they
are switched off inside WoE and GvG castles.
