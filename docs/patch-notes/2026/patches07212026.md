# Patch Notes - July 21, 2026

!!! warning "Important"
    Make sure your client is patched using the patcher -
    this is important to avoid in-game errors and crashes.

## 🎮 Gameplay

| Change | Description |
|--------|-------------|
| **Eternal Bastion Weekly Runs** | **Eternal Bastion** can now be run `2` times per week (up from `1`). All mechanics remain the same |
| **Quick Cooking** | Cook the same dish `4` times in a row (each within `5` seconds of the last) and **Quick Cooking** activates, announced in chat. While active, using a cooking kit instantly cooks that dish again with no menu selection, as long as you have the materials. Normal success rates still apply. Waiting more than `5` seconds or cooking a different dish deactivates it |
| **Misty Island Warp** | **Misty Island** added to Warpra's dungeon list, with a return Warpra on the island itself |
| **1 Billion Zeny Token** | **Bill Doors** in Prontera `(100, 253)` exchanges `1,000,000,000` zeny for a **1B Zeny Token** and back, letting you store zeny above the `2` billion carry cap as an item |

## ⚔️ Skills

### Berserk Rework (Lord Knight)

<img src="../../../img/skill_359.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Berserk** has been reworked. Core numbers are unchanged (HP `x3`, `+100%` damage, ASPD `+30%`, `5` minute duration, HP drain). What changed:

- <img src="../../../img/601.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Fly Wing**, <img src="../../../img/12323.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Novice Fly Wing**, and <img src="../../../img/12887.gif" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Infinite Fly Wing** can now be used while Berserked. All other items remain blocked.
- You can now chat while Berserked.
- If <img src="../../../img/skill_357.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Concentration** is active when you cast Berserk, it is refreshed and extended to `2.6x` its normal duration (Lv5: from `45` to `117` seconds). Concentration now ends when Berserk ends.
- New visuals: the red body tint is replaced with an aura effect and a cast sound. You can hide the aura on your own character via the **Status Color Effect** setting.

### Monk & Champion Combo SP Costs

Monk and Champion combo skill SP costs have been reduced by roughly half:

| <img src="../../../img/skill_273.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Raging Thrust** | `11/12/13/14/15` SP | `2/4/6/8/10` SP |
| <img src="../../../img/skill_370.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Raging Palm Strike** | `2/4/6/8/10` SP | `1/2/4/6/8` SP |
| <img src="../../../img/skill_371.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Glacier Fist** | `4/6/8/10/12` SP | `2/3/4/5/6` SP |
| <img src="../../../img/skill_372.png" alt="" style="vertical-align:middle;width:1.25rem;height:1.25rem;"> **Chain Crush Combo** | `4-22` SP | `2-11` SP (spirit sphere cost unchanged) |
