# Patch Notes - October 28, 2026

!!! warning "Important"
    Make sure your client is patched using the patcher -
    this is important to avoid in-game errors and crashes.

---

## 🎮 Gameplay

### Autotrade 2

- Added a client side indicator to the character select screen when a character is in `@at2` status.
- `@at2` no longer blocks you from logging back into the character for a few seconds after a sale. Logging back in closes the shop, and all Zeny and items from sales carry over to your character.

:point_right: **[Autotrade 2](../../vendor-system.md#autotrade-2)**

### Card Drop Illustration

Added a card art animation that pops up on the bottom right of your screen when you loot a card from a monster. It disappears after `5` seconds.

- Only for cards that show the server drop announcement, and only for the player who gets the card.
- Can be turned on/off in **`@settings`** (**Card Drop Illustration**).

## 🎒 Items

| Item | Changes |
|------|---------|
| **Celine Kimi Card** | Fixed the MVP card to properly inflict **Critical Wounds** on the target (monsters / players) instead of the player who uses the card |
| **Costume Nightmare Chain** | Changed from a lower costume to the shadow accessory slot, to match ViewSprite ID `0` and effect based costumes. It also shows up in costume preview following this change |

!!! note "Re-equip Required"
    If you have **Costume Nightmare Chain** equipped, you will need to equip it again.

## 🎃 Halloween Event 2026

| Change | Description |
|--------|-------------|
| **Spooky Memories** | The 7-day Halloween quest now properly saves day to day |
| **Pumpkinring** | No longer spawns if you're capped on all Halloween loot for the day (coins, cakes and treat baskets) |
| **October Event Rewards Box** | Removed **Transform Candy** from the box and updated its description |

!!! note "Spooky Memories Progress"
    The fix doesn't change anyone's progress. You continue where you left off before maintenance. It only stops further resets.

### The Last Performance

Performance update to mitigate client side lag due to mob count for lower end hardware / configurations:

| Change | Before | After |
|--------|--------|-------|
| **Valkyrie HP** | `2500` | `2000` |
| **Valkyrie Heal (next wave)** | `25%` | `20%` |
| **Spawn Count (per side)** | `10` / `20` / `30` | `8` / `8` / `8` |
| **Spawn HP** | - | Around `+40%` wave `2`, `+55%` wave `3` |
| **Himmelmez HP (per member)** | `250` | `200` |

:point_right: **[Halloween Event 2026 Guide](../../halloween-event-2026.md)**
